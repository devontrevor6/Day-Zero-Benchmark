# Security Policy

## Supported Versions

The following versions of the benchmark utility are currently monitored for operational stability and dependency updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As an open-source diagnostic project, maintaining secure development practices is a priority. If you discover a logic error, dependency vulnerability, or a bug in the timing loop mechanics, please report it responsibly:

1. **Do Not Open a Public Issue:** Please refrain from opening a public issue on the GitHub tracking board to prevent unpatched bugs from being exposed.
2. **Contact:** Open a private discussion thread or contact the project maintainer directly to share your findings.
3. **Response Timeline:** You can expect an initial acknowledgement within 48 hours, followed by updates on remediation steps if a software adjustment is required.
